# 🌦️ Weather Dashboard

A modern **Weather Dashboard Web App** built using **HTML, CSS, and JavaScript** that provides real-time weather data, forecast, and a live scrolling weather ticker.

---

## 🚀 Features

### 🔍 City Search

* Search weather by city name
* Displays:

  * Temperature 🌡️
  * Wind Speed 💨
  * Humidity 💧
  * Weather Condition 🌤

---

### 🌤 Dynamic Weather Icons

* Automatically shows:

  * ☀️ Sun (Day)
  * 🌙 Moon (Night)
  * ☁️ Cloud
  * 🌧 Rain
  * ⛈ Thunderstorm

---

### 📅 4-Day Forecast

* Shows upcoming weather for 4 days
* Includes:

  * Date
  * Condition
  * Temperature
  * Wind
  * Humidity

---

### 📊 Live Weather Ticker 

* Displays multiple cities’ temperatures
* Smooth infinite scrolling
* Pauses on hover
* Works like stock market ticker

---

### 🌍 API Integration

* **OpenWeatherMap API** → Current weather & forecast
* **Open-Meteo API** → Live ticker data

---

## ⚙️ Setup Instructions

1. Clone the repository:

```
git clone https://github.com/your-username/weather-dashboard.git
```

2. Open the project folder

3. Add your API key in `script.js`:

```javascript
const apiKey = "YOUR_API_KEY";
```

4. Open `index.html` in your browser

---



## 💡 How It Works

1. User enters a city name
2. JavaScript sends request to weather API
3. API returns JSON data
4. Data is displayed dynamically
5. Forecast & ticker update automatically
